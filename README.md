# 맨큐 연습실

제공된 PDF 목차의 1, 3, 4, 5, 6, 7, 9장 간단한 퀴즈와 응용 문제를 위한 학습 사이트입니다.

`docs/`를 GitHub Pages의 main 브랜치 배포 폴더로 사용합니다. 별도 빌드가 없습니다.

- 원문 이미지로 수식과 표를 보존합니다.
- 퀴즈는 교재 장 끝 정답표로 채점합니다.
- 응용 문제는 풀이 메모와 학습 완료 표시를 지원하며 공식 해설을 포함하지 않습니다.
- 학습 기록은 localStorage에 저장하고 JSON으로 내보내거나 가져올 수 있습니다.
- PDF 전체와 강의 자료는 저장소에 포함하지 않습니다.

원문 발췌의 저작권은 원저작권자에게 있습니다.
