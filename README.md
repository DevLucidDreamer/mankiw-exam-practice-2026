# 맨큐 연습실

제공된 교재·강의자료를 바탕으로 만든 경제학입문 시험 대비 사이트입니다.

- 기존 범위: 1, 3, 4, 5, 6, 7, 9장.
- 2장 범위: **MQ1/ch02.pptx의 18번 슬라이드만**. 실증적 주장과 규범적 주장의 구분입니다.
- 교재 퀴즈 68개·응용 문제 74개에 자체 작성 해설을 제공합니다.
- 개념 OX는 8개 장에 각 20개씩 총 160개이며, 모든 문항에 해설이 있습니다. 총 302문항입니다.

`docs/`를 GitHub Pages의 main 브랜치 배포 폴더로 사용합니다. 별도 빌드가 없습니다.

- 원문 이미지로 수식과 표를 보존합니다. 간단한 퀴즈 68문항(77개 이미지)은 필기 없는 `맨큐의 경제학 제 9판.pdf`에서 추출하며, 일반 연습과 모의고사에서 같은 이미지를 사용합니다. 응용 문제의 원문은 기존 PDF를 유지합니다.
- 퀴즈는 교재 장 끝 정답표로 채점합니다.
- 퀴즈·OX는 채점 후 해설이 표시되고, 응용 문제는 ‘해설 보기’로 풀이를 확인합니다. 자체 작성 해설이며 교재 공식 해설은 아닙니다.
- 5장 퀴즈 11번은 교재 정답표를 유지하면서 동시 변화의 정보만으로 탄력성을 식별하기 어렵다는 주석을 붙였습니다.
- 오답 필터, 북마크, 문제 섞기, 다시 풀기와 응용 문제의 학습 완료 표시를 지원합니다.
- 학습 기록은 localStorage에 저장하고 JSON으로 내보내거나 가져올 수 있습니다.
- PDF 전체와 강의 자료는 저장소에 포함하지 않습니다.

원문 발췌의 저작권은 원저작권자에게 있습니다.

## 모의고사

상단 ‘모의고사’에서 시험을 시작합니다. 기본 설정은 전 범위의 퀴즈·OX 30문항, 30분입니다. 장별 범위, 문제 유형, 문항 수(10·20·30·50·100·전체), 제한시간을 선택할 수 있습니다. 해당 범위의 문항이 적으면 있는 문항을 중복 없이 모두 출제합니다.

매 시험을 시작할 때 문제 순서를 섞습니다. 시험 중에는 정답·해설을 숨기며 번호 이동, 다시 볼 문항 표시, 답안 지우기, 미응답 확인을 지원합니다. 답안과 절대 종료시각을 `mankiw-mock-exam-v1`에 저장하므로 새로고침해도 같은 순서와 남은 시간으로 이어 풉니다. 제한시간이 끝나면 자동 제출합니다. 일반 연습의 풀이·메모·북마크는 덮어쓰지 않습니다.

제출 후 퀴즈·OX를 같은 배점으로 자동 채점하고 미응답은 오답으로 계산합니다. 응용 문제는 자동 점수에서 제외하며 해설과 비교해 자기 채점합니다. 오답·미응답이나 표시한 문항을 모아 복습할 수 있고, 오답만 섞어 새 시험을 시작할 수 있습니다. 최근 한 회의 시험을 보관하며 새 시험을 시작하면 교체됩니다.

## 데이터 편집

`textbook-data.json`은 원문 문항의 기본 데이터입니다. 자체 해설은 `content/explanations-장.txt`, OX는 `content/ox-장.txt`에서 관리합니다. OX 한 줄의 형식은 `o 또는 x|주제|문장|해설`입니다.

내용 변경 후 `python enrich.py`로 `docs/data.json`을 재생성합니다. `extract.py`로 원문 이미지를 다시 추출하면 기본 데이터를 갱신한 뒤 `enrich.py`를 실행합니다. 기존 문항 ID와 localStorage 키 `mankiw-study-v1`을 유지하여 이전 기록을 이어 쓸 수 있습니다. 이전 버전 JSON 백업도 가져올 수 있습니다.

간단한 퀴즈 이미지만 교체할 때는 `python replace_quiz_images.py`를 실행합니다. 기본 원본은 상위 폴더의 `맨큐의 경제학 제 9판.pdf`이며, `--pdf`로 다른 위치를 지정할 수 있습니다. 제9판 전용 자르기 좌표는 `quiz-clean9-layout.json`에서 관리합니다. 교재 쪽수와 새 PDF의 물리적 쪽수(교재 쪽수 + 32)를 함께 기록하고, 새 이미지는 `docs/questions/clean9/`에 저장하여 이전 이미지 캐시와 구분합니다. `extract.py`로 전체를 다시 추출해도 간단한 퀴즈에는 반드시 제9판을 사용합니다.

## 브라우저 확인

`python -m http.server 8765 --bind 127.0.0.1 --directory docs`로 서버를 실행한 뒤 `python verify_site.py`를 실행합니다. Python Playwright와 Edge를 사용하여 채점, 필터, 해설, 기록 내보내기·가져오기, 이전 기록 호환성, 전체 문항 렌더링과 모바일 너비를 확인합니다.

`python verify_exam.py`로 출제 범위와 중복 방지, 제출 전 정답 숨김, 점수 계산, 오답 재시험, 답안 복원, 실제 타이머·새로고침 후 자동 제출, 서술형 자기 채점, 기존 연습 기록 보존과 모바일 화면을 확인합니다. `SITE_URL` 환경변수로 실제 배포 주소를 지정할 수도 있습니다.

`python verify_clean_quizzes.py`로 제9판 퀴즈 68문항의 ID·정답·쪽수와 새 이미지 77개의 파일 무결성을 검사하고, 브라우저에서 전체 이미지를 불러와 일반 연습·모의고사 적용을 확인합니다.
